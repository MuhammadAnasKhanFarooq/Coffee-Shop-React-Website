# Coffee Shop React Website

A basic fourth-semester React single-page project created to practice reusable components, props, and frontend styling.

The project displays different coffee, drink, and food items using reusable React components.

## Features

- Single-page coffee shop interface
- Header component
- Navigation bar
- Reusable `ProductCard` component
- Product name, price, and image passed using props
- Coffee, drinks, and food sections
- Footer component
- Basic CSS styling

> The navigation links and "Add to Cart" buttons are interface elements only. Routing and cart functionality were not implemented in the original academic project.

## Technologies Used

- React
- JavaScript
- JSX
- CSS
- Vite

## Project Structure

- `App.jsx` — main application layout
- `Header.jsx` — page header
- `Navbar.jsx` — navigation bar
- `ProductCard.jsx` — reusable product component
- `Footer.jsx` — page footer
- `App.css` — project styling
- `main.jsx` — React application entry point

## How to Run

1. Clone or download the repository.

2. Open the project folder in VS Code.

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local address shown in the terminal.
